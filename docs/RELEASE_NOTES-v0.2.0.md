# 胖宝宝独立桌宠 v0.2.0

桌面广播体操继续营业。下载并解压 `PangBaoBaoPet-0.2.0-win-x64.zip` 后运行 `PangBaoBaoPet.exe`；需要 Windows 10/11 x64 与 .NET 8 Desktop Runtime。

## 这次更新

- 伸展、转体、踮脚分别更新为 36、24、20 帧的 24 FPS 动作循环。
- 清理旧素材的可见紫色残边，减轻伸展动作的半透明白边。
- 右键菜单保留三节原版动作，方便比较和单节循环。
- 继续支持随机对话气泡、可编辑文案和概率、拖动、缩放、速度、置顶及托盘退出。

扩胸、体前屈、侧弯仍为 5–6 帧预览动作。补帧时少数手部、面部和鞋子纹理仍可能短暂变化。已在本机完成构建、气泡规则测试、桌面显示与全新解压目录启动验证；其他电脑尚待验证。
