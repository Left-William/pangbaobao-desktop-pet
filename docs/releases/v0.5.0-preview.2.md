# 0.5.0-preview.2｜睡衣短舞步与单动作循环

睡衣造型新增三段可独立播放的舞步：机械锁舞（1.46 秒）、横移滑步（1.36 秒）、托马斯回旋（1.75 秒）。每段可在右键「运动动作」中选择「播放一次」或「单独循环」；选择「返回广播体操」退出循环。摸头、飞吻等互动结束后会接回原循环，换衣会退出循环。原有约 5 秒的睡衣街舞组合也支持单独循环。

三个短舞步采用写真关键姿势，刻意保留夸张姿态与清楚的节奏跳变，尤其是托马斯回旋的单手支撑和甩腿。它们不是高帧率视频动画。运行时继续保留独立 Windows 桌宠、双服装切换、可收起的对话框、可配置的兼容对话 API、人设、漫画气泡及好感度系统。
