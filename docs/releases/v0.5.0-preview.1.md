# 0.5.0-preview.1｜睡衣街舞预览

这次预览把桌宠封装成可独立运行的 Windows x64 程序，重点加入睡衣街舞。穿睡衣后，右键桌宠选择「运动动作」→「街舞组合」，可看他从交叉步下地、做两圈风车、定格，再起身回到原动作。街舞采用 20 个播放帧、13 张不同的写真关键姿势，约 5 秒；这是快速剪辑风格，姿势之间仍有可见跳变。

同时提供睡衣／黑 T 恤切换、桌宠下方可收起的外部 API 对话框、可编辑人设，以及原有的漫画气泡、摸头爱心、好感度和广播体操。外部 API 地址、模型与密钥由用户自行填写；没有配置时可用本地台词。

## 下载

- `PangBaoBaoPet-0.5.0-preview.1-win-x64-selfcontained.zip`：便携版，完整解压后运行 `PangBaoBaoPet.exe`，无需另装 .NET。
- `PangBaoBaoPet-0.5.0-preview.1-win-x64-setup.exe`：按当前用户安装的预览安装包，无需另装 .NET。安装包尚未签名。

支持 Windows 10/11 x64。更多操作见 [安装说明](../安装说明.md)。
