# 胖宝宝独立桌宠 0.3 实施记录

日期：2026-09-24
版本：`0.3.0-preview.1`
范围：独立 Windows WPF 桌宠的漫画对白、好感度、特殊动作和广播操节奏。

## 已接入

| 功能 | 实际实现 |
| --- | --- |
| 漫画气泡 | WPF 浅色对白框、三角尾巴、头部锚点；按窗口所在屏幕方向选侧，长文本按字素分页 |
| 台词 | 日常、摸头、拖动、飞吻、打滚五种语境；文案逐条编辑、启停；随机气泡概率与互动气泡概率分开 |
| 摸头 | 点击人物上部且点中非透明像素时，冒爱心并播放一次娇羞动作；双击保留气泡预览 |
| 好感度 | 点击 +1、有效拖动 +2，分别 3 秒与 10 秒计分冷却；60 秒最多 +6；范围 0～100，无自然衰减 |
| 特殊动作 | 30 首次飞吻、70 首次打滚；首次奖励入队并在一节广播操结束时衔接；完成后回到此前模式 |
| 存档 | `%APPDATA%\PangBaoBaoPet\pet-state.json`，独立于设置文件，写入时保留备份；旧版无存档时从零开始 |
| 广播操 | 伸展、转体、踮脚从 0.2 补帧中筛选 18／12／12 帧，给不同阶段单独设置停留时间，默认六节约 21.07 秒 |

气泡仍可手动预览。关闭自动气泡只影响自动台词；关闭好感度计分后，摸头的爱心和娇羞反馈仍在。菜单提供好感度数值、特殊动作预览与进度重置。

## 验证结果与范围

1. 便携 .NET 8 SDK 在 Windows 本机构建 Release，零编译警告。
2. 烟雾测试覆盖随机气泡 0%／100% 与冷却、设置兼容迁移、好感度计分限流、30／70 门槛、待播奖励和坏档备份恢复。
3. 隔离配置启动实际窗口，验证气泡与新动作的渲染。测试配置中预置 29 分，触发一次摸头后升至 30：先播娇羞，再播飞吻，存档中 `PendingMilestones` 清空且 `CompletedMilestones` 只有 `kiss`。
4. 已从 ZIP 全新解压目录启动程序，确认人物与气泡显示、进程保持运行。

最终 ZIP：`PangBaoBaoPet-0.3.0-preview.1-win-x64.zip`，12,786,695 字节，SHA-256：`E533C137EC89E258FF814770814A26214A286628F8DAE0B9D03E00694C08CB11`。最终封装重新解压后含 178 张 PNG 动作帧，独立启动进程保持运行。

实际鼠标点击与拖动的系统输入路径，受本次自动化环境限制，未完成可复核的真实手势测试；第 3 项通过临时的 Debug 场景钩子触发相同的互动逻辑，钩子已从正式源码移除。其他电脑、多显示器、不同 DPI、长期运行与 70 分门槛的完整界面流程尚待体验反馈。桌宠动作是否“自然”仍需用户在自己的桌面上观看连续预览，不以静态截图代替主观验收。

## 与原规划的取舍

- 保留现有 WPF 与透明 PNG 逐帧播放器。没有引入运行时补帧库或新桌宠框架。
- 未为每个中间帧单独标嘴部锚点；当前每组动作使用头部附近的共同锚点，并在打滚结束后才显示动作台词。
- 飞吻和打滚是少量关键姿势按阶段播放，避免把整个人像做光流变形。打滚目前是预览级的蹲下、侧卧、仰卧、起身序列，尚非高帧数连续翻滚。
- 0.2 的原补帧仍在仓库，0.3 对三节动作只挑选部分姿势并拉长到位时间。扩胸、体前屈、侧弯依旧使用 6 帧原始素材。

本记录只描述已验证的部分，不代表视觉体验已经得到用户确认。
