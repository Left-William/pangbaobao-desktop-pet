# 胖宝宝独立桌宠 v0.2.0：安装说明

## 运行环境

- Windows 10/11 x64
- [Microsoft .NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

## 启动

1. 完整解压 `胖宝宝独立桌宠-0.2.0.zip`。
2. 保持 `PangBaoBaoPet.exe` 与 `Assets` 文件夹在同一个目录。
3. 双击 `PangBaoBaoPet.exe`。

左键拖动人物。右键选择整套广播体操、单节循环、播放速度、缩放、置顶、气泡设置和退出。双击人物可立即预览一句气泡。找不到窗口时，从系统托盘中的「胖宝宝桌宠」选择「显示桌宠」。

## 气泡与设置

右键打开「设置对话气泡…」，可设置每条文案是否启用、判定间隔、命中概率、冷却时间及停留时间。默认每 300 秒判定一次、命中率 20%、气泡显示 5 秒、消失后冷却 600 秒。

设置保存在 `%APPDATA%\PangBaoBaoPet\settings.json`，并保留 `.bak` 备份。需要便携配置时，可在启动前把环境变量 `PANGBAOBAO_CONFIG_DIR` 指向可写目录。

本包是依赖 .NET 8 Desktop Runtime 的版本。动画素材已随包附带，运行桌宠不需要 RIFE、Python 或 Codex。
