# 胖宝宝独立桌宠：安装说明

公开 Release 仍为 v0.3.0-preview.1；源码工作区可用 `tools/package.ps1` 生成 v0.5.0-preview.1 本地预览包。0.5 尚未完成视觉验收，动作覆盖情况见 [实施记录](0.5-实施记录.md)。

## 运行环境

- Windows 10/11 x64
- [Microsoft .NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

## 安装与启动

1. 下载公开版 `PangBaoBaoPet-0.3.0-preview.1-win-x64.zip`，或使用本地构建的 `PangBaoBaoPet-0.5.0-preview.1-win-x64.zip`，完整解压到一个普通文件夹。
2. 保持 `PangBaoBaoPet.exe` 与 `Assets` 文件夹在同一目录，不要只复制 EXE。
3. 双击 `PangBaoBaoPet.exe`。找不到人物时，从系统托盘中的「胖宝宝桌宠」选择「显示桌宠」。

运行桌宠无需 Python、RIFE 或 Codex；本包依赖系统安装的 .NET 8 Desktop Runtime。

## 互动

- 轻点头部：冒出爱心，短暂播放娇羞动作；双击人物可预览台词。
- 拖动人物：改变桌面位置。有效点击和拖动分别增加好感度，连点有冷却和每分钟上限。
- 好感度到 30 首次触发飞吻，到 70 首次触发打滚。特殊动作在当前广播操结束后接入，完成后回到此前模式。
- 右键：查看好感度、重置进度、预览特殊动作，或调整整套／单节动作、播放速度、缩放和置顶。
- 0.5 本地预览：右键「服装」切换印花睡衣或黑 T 恤；当前动作播放完再换。两套服装都能单节循环九帧写真伸展和十一帧写真扩胸；黑 T 恤自动播放会在这两节之间循环，还有娇羞、六帧跳远、六帧跳高与十五帧两次俯卧撑关键姿势预览。俯卧撑播放时会临时展开横向透明窗口，结束后回到原位置。黑 T 恤其余四节广播操、引体向上和街舞仍未完成。

## 气泡与设置

右键进入「设置对话与互动…」，可逐条编辑日常、摸头、拖动、飞吻、打滚台词及启用状态；随机气泡与互动气泡的概率分开设置。默认日常气泡每 300 秒判定一次，命中率 20%，显示 5 秒，消失后冷却 600 秒。互动气泡概率默认 25%。关闭自动气泡后，手动预览仍可用。

设置在 `%APPDATA%\PangBaoBaoPet\settings.json`，好感度在同目录的 `pet-state.json`。各自保留 `.bak` 备份。从 0.2 升级时，原有日常台词保留，新语境台词会在首次加载旧版设置时补入。需要便携配置时，在启动前将环境变量 `PANGBAOBAO_CONFIG_DIR` 指向可写目录。

这个版本是动作节奏和互动的预览版。首次运行、切换显示器或调整 DPI 后，建议先试点头部、拖动和右键菜单；发现错位可回报截图及系统缩放比例。

## 0.5 本地预览的外部对话

桌宠下方的「💬」图标可展开紧凑对话框；在「聊天」页输入后点击发送，或用 Ctrl+Enter 发送。「−」会收起为图标；聊天闲置 2 分钟、配置／人设页闲置 5 分钟后也会收起。右键桌宠选「展开下方对话框」同样可打开。屏幕下方空间不足时会调整桌宠位置，仍放不下才把框放在侧边。

在对话框的「对话 API 设置」页填写完整的 chat completions 兼容接口地址、模型名称和 API 密钥，或在「人设」页修改文字。密钥经 Windows 当前用户 DPAPI 加密，保存到 `%APPDATA%\PangBaoBaoPet\dialogue-api.key.dpapi`；接口配置在 `dialogue-api.json`，人设在 `prompts\persona.md`。使用 `PANGBAOBAO_CONFIG_DIR` 时，这三项也改存到指定目录。密钥跨 Windows 用户或电脑不能自动解密，需要重新填写。

外部 API 默认关闭。未配置或服务不可用时，桌宠仍能用本地台词；聊天窗口会标出本地台词来源。默认只有手动发送和测试连接会请求 API；勾选「允许偶尔自动调用 API」后，自动气泡才可能调用，每天最多 30 次、至少间隔 120 秒，次数保存在 `dialogue-usage.json`。测试连接和自动回复都可能计费。当前只验证了本地模拟服务，使用某个具体供应商前需在其接口上实测。
