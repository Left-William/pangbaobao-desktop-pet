# 睡衣街舞关键姿势检查

日期：2026-09-26。对应 `0.5.0-preview.1`，动作 ID 为 `pajamas/street_dance`。

## 动作与素材

- 20 个播放帧、13 个不同 PNG，约 5.05 秒；宽舞台为 768×576 DIP。两圈风车复用同一组五张关键姿势，不能将播放帧数解释为 20 张独立画面或连续高帧率视频。
- 顺序：站立 → 两种交叉步 → 单手下地 → 六步腿伸展 → 两圈风车 → 单手／前臂定格 → 单膝恢复 → 起身收尾 → 站立。前后保留原睡衣站立帧，方便退出时回到广播操。
- 新人物姿势沿用已确认的睡衣人物标准；竖幅源图为 1024×1536，横幅为 1536×1024，按清单显示高度 361 DIP 缩放。街舞每帧有效源像素／显示 DIP 均大于 2。
- 候选图和抠图过程保留在 Git 忽略的 `art/candidates/pajamas/`，运行时只包含 `Assets/pajamas_street_dance_photo/`。人像抠图模型把六步动作右腿误删，故六步运行帧采用保留完整腿部的原始透明图；其余新姿势使用逐张检查过的抠图结果。原始人物照片不在仓库或发行包内。

## 视觉核查

[动画预览](pajamas-street-dance.webp)；[灰底逐帧](pajamas-street-dance-gray.png)、[白底逐帧](pajamas-street-dance-white.png)、[黑底逐帧](pajamas-street-dance-black.png)。三种背景用于检查人物边缘和地面相对位置；逐帧排版可见伸出的四肢、衣服、眼镜和发型，没有发现截断或误抠的主体。背景图是离线模拟 WPF 清单高度和偏移的审片图，实际透明窗口的不同 DPI／多显示器显示仍应由后续使用反馈核对。

## 性能与范围边界

风车每姿势约 100～130 ms，两圈快速切换，停在定格画面 650 ms。它属于夸张的写真关键姿势剪辑，动作之间存在可见跳变；本地 LTX-Video 试验虽能生成短片，却出现模糊、裁切、脸部漂移，未采纳为正式帧。正式工程规划中的 160～260 帧／120 张有效画面、高连续性 Windmill 仍待后续版本。旧踮脚、侧弯、打滚等低密度动作与睡衣跳远、跳高、引体向上、俯卧撑等缺项也留待后续更新。
