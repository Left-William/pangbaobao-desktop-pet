# 胖宝宝独立桌宠 v0.3.0-preview.1

桌面广播体操现在会留一点到位时间。摸摸他的头，他会冒爱心、害羞一下；好感度够了，还会飞吻和打滚。

## 新增

- 漫画对白气泡：带指向角色的尾巴，日常、摸头、拖动和特殊动作台词可分别编辑。
- 好感度 0～100：有效点击 +1、拖动 +2，有限流和本地存档；30 首次飞吻，70 首次打滚。
- 摸头娇羞、飞吻、打滚三组照片风格关键姿势；特殊动作播完回到广播体操。
- 右键查看或重置好感度，预览特殊动作。

## 动画节奏

- 伸展、转体、踮脚分别从旧补帧中筛为 18、12、12 张姿势，按不同帧时长播放；默认六节总长约 21 秒。
- 旧版动作帧保留在仓库，供对照。扩胸、体前屈、侧弯目前仍为 6 帧动作。

## 安装与已知边界

Windows 10/11 x64，需安装 .NET 8 Desktop Runtime。完整解压 `PangBaoBaoPet-0.3.0-preview.1-win-x64.zip` 后运行 `PangBaoBaoPet.exe`。

这是预览版。新姿势来自参考人物的图像生成，少量衣纹和边缘可能与旧动作有差异；多显示器、不同 DPI 和真实鼠标手势仍需要更多机器反馈。项目内的源码和测试已在 Windows 上构建，详见 [实施记录](0.3-实施记录.md)。
